# Ladra Claro

Sitio estático de adiestramiento canino y tienda de accesorios, preparado para desplegarse en Vercel.

## Despliegue en Vercel

1. Sube la carpeta `WEB` a un repositorio de GitHub, o importa el repositorio desde el panel de Vercel.
2. En **Root Directory**, selecciona `WEB` si el repositorio contiene más carpetas.
3. Deja el framework como **Other**.
4. No hace falta indicar comando de build ni carpeta de salida.
5. Pulsa **Deploy**.

La web utiliza imágenes remotas de Unsplash y la tipografía de Google Fonts, por lo que necesita conexión a internet para mostrar todos los recursos visuales.
